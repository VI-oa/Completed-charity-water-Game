# Charity: water Game Prototype

In this project, you’ll begin transforming your game concept from last week into a working interactive prototype using HTML, CSS, and JavaScript.

## How to play

- Choose Easy, Normal, or Hard before starting. Each mode changes the can goal, time limit, and falling-object pace; Hard also gives you fewer lives.
- Collect the number of clean water cans shown in the score display before the timer runs out.
- Avoid dirty drops. Easy and Normal give you 3 lives; Hard gives you 2. The game ends when they are gone.
- Move with the left and right arrow keys, **A** and **D**, the on-screen buttons, or by tapping/clicking where you want to move.
- Choose **Reset** at any time to start over.
- Caught cans and dirty drops disappear from the game area. Reach the selected can goal to win and celebrate with confetti.
- Use the links below the game to visit charity: water or its donation page.
