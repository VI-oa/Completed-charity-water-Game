# Charity: water Game Prototype

In this project, you’ll begin transforming your game concept from last week into a working interactive prototype using HTML, CSS, and JavaScript.

## How to play

- Collect 10 clean water cans before the 90-second timer runs out.
- Avoid dirty drops. You have 3 lives; the game ends when they are gone.
- Move with the left and right arrow keys, **A** and **D**, the on-screen buttons, or by tapping/clicking where you want to move.
- Choose **Reset** at any time to start over.
- Collect all 10 cans to win and celebrate with confetti.
